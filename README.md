# LevelRange-Turtle

Показывает диапазон уровней зон на карте мира (World Map) для Turtle WoW 1.18.1 (API 1.12).
Форк аддона LevelRange-Turtle by [Spartelfant](https://github.com/Spartelfant).
Author:         Bull3t, Tenyar97, rado-boy, blehz, rafacc87, Diginfotek, Spartelfant, Zaiia.
Addon Website:  https://github.com/ZaiiaDS/LevelRange-Turtle/

---

## Возможности

- Диапазон уровней зоны (мин–макс) прямо в тултипе на карте мира.
- Цветовая маркировка по фракции: своя — зелёным, враждебная — красным, спорная — коричневым.
- Минимальный уровень рыбной ловли для каждой зоны.
- Список подземелий и рейдов с рекомендуемыми уровнями.
- Полная локализация: enUS, ptBR, ruRU, zhCN.
- Окно настроек с чекбоксами и настройкой размера шрифта (слайдер + поле ввода).

## Исправления

### Критические

- **Локализованные `LEVELRANGE_ALLIANCE`/`LEVELRANGE_HORDE` ломали определение фракции.** На не-английских клиентах сравнение `UnitFactionGroup()` (возвращает `"Alliance"`/`"Horde"`) с локализованными строками давало неверный результат — все зоны своей фракции отображались как враждебные. Разделены на внутренние маркеры (английские) и отображаемые строки (локализованные).
- **Зависимость от myAddOns.** Удалена полностью. Функции `OptionsFrame_EnableCheckBox`/`OptionsFrame_DisableCheckBox` теперь определены локально в аддоне.
- **`DEFAULT_LEVELRANGE_SHOWFISHING` не была определена.** Инициализация настроек не заполняла `showFishing`, из-за чего рыбалка никогда не отображалась. Дефолты перенесены в единую таблицу внутри `LevelRange_Initialize`.

## Улучшения

### Интерфейс

- **Окно настроек:**
  - Кнопка `Close` заменена на стандартный крестик (`UIPanelCloseButton`) в правом верхнем углу.
  - Закрытие по `Esc` через регистрацию в `UISpecialFrames`.
  - **Настройка размера шрифта тултипа** (диапазон 8–24, по умолчанию 14) через слайдер и поле ввода, синхронизированные между собой. Значение сохраняется в `SavedVariables`.

## Чистка кода

- Удалены глобальные переменные `Details`, `Help`, `playerName`, `realmName`, `LEVELRANGE_NAME`, `DEFAULT_LEVELRANGE_*` — всё локализовано там, где возможно.
- Удалены мёртвые константы в локалях: `LEVELRANGE_NAME`, `LEVELRANGE_DESCRIPTION`, `LEVELRANGE_INSTANCES1..19`, `LEVELRANGE_DEFAULT_OPTS`, все `LEVELRANGE_HELP*`.
- Объединены идентичные функции `getInstanceLevels` и `getRaidLevels` в одну `addInstanceLines`.
- Убраны избыточные `== true` в условиях.
- Убраны смешанные точки с запятой.
- Убраны повторяющиеся разделители комментариев и закомментированный мусор.
- Из XML удалён `text="..."` у заголовка окна настроек (переопределялся в Lua).
